# SSH 사슬의 갭 안 상태 — 에지 상태의 정체와 유지 조건 (전산물리학 기말 프로젝트)

## Physics question

> $t_2>t_1$일 때 SSH 사슬의 갭 안에 생기는 상태는 무엇이고, 어떤 조건에서 유지되는가?

중간 프로젝트(`midterm-tight-binding/`)의 예비 관찰, 즉 "끝이 있는 사슬에서 $t_2>t_1$이면 갭 안에 $E\approx0$ 상태가 2개 있다"를 이어서 그 원인과 유지 조건을 검증하고 해석한다.

계산한 양: 상태의 진폭 분포와 국소화 길이, 영 근처 에너지 $\min\lvert E\rvert$의 사슬 길이 의존성, 카이랄 대칭의 수치 확인, 난수 무질서에서의 영 근처 에너지(평균 ± 표준오차), 회전수.

**결론 (수치로 확인)**
1. 갭 안의 상태는 사슬 한 끝에 국소화된 **한 부격자(A 또는 B) 한정 상태**이고 진폭이 셀마다 $t_1/t_2$배로 준다. 규격화 조건 때문에 $t_2>t_1$일 때만 존재한다.
2. 유한 사슬에서는 두 끝 상태가 섞여 $\pm\epsilon$으로 갈라지고, $\lvert\epsilon\rvert=t_1(1-r^2)r^{N_c-1}$ ($r=t_1/t_2$, 1차 섭동)이 대각화 결과와 일치한다.
3. 이 상태가 $E=0$ 근처에 남는 것은 카이랄 대칭 덕분이다. hopping 무질서(대칭 유지)에서는 유지되고 온사이트 무질서(대칭 깨짐)에서는 $E=0$에서 떨어진다.

모델: 단위셀에 A, B 두 원자, 셀 안 hopping $t_1$, 셀 사이 hopping $t_2$, 셀 수 $N_c$. 가정: 최근접 hopping만, 오비탈 직교, 온사이트 에너지 없음. 경계조건: 열린(유한 사슬), 회전수는 주기. 규약: A 원자에서 시작하고 첫 결합이 $t_1$.

수치 방법: $2N_c\times2N_c$ 실공간 행렬 대각화 (`numpy.linalg.eigh`). 끝이 있어 Bloch 정리를 쓸 수 없고, 작아서 정확하며 수렴 변수가 없다.

## Validation and limitations

### 기준과의 비교 (해석값, 극한)

| 비교 | 수치 | 이론 |
|---|---|---|
| 이웃 셀 진폭비 ($t_1/t_2=0.5$) | 0.5000 | 0.5 |
| 진폭 감쇠율 (0.5 / 0.8) | $-0.6931$ / $-0.2231$ | $-0.6931$ / $-0.2231$ |
| 첫 사이트 확률 (0.5 / 0.8) | 0.7500 / 0.3600 | $1-r^2$: 0.75 / 0.36 |
| 극한 $t_1\to0$ | 끝 원자 확률 1.0000 | 1 |
| 반대 부격자 가중치 | $\sim10^{-31}$ | 0 |
| 국소화 길이 (0.5 / 0.8 / 0.95) | 1.44 / 4.48 / 19.5 셀 | $1/\ln(t_2/t_1)$ ($r\to1$에서 발산) |

($r=0.95$의 첫 사이트 확률은 60셀 사슬에서 유한 길이 영향으로 0.0992이고 이론 0.0975와 약간 다르다.)

### 수치 해상도: 영모드 분리 vs 사슬 길이

$(t_1,t_2)=(0.5,1)$: $N_c=10,20,40$에서 $\min\lvert E\rvert=7.32\times10^{-4},\ 7.15\times10^{-7},\ 6.82\times10^{-13}$, 1차 섭동 $t_1(1-r^2)r^{N_c-1}$과 일치 (수치/이론 1.000).
$(0.8,1)$: $N_c=10$에서 3.8 %, $20$에서 0.1 % 차이, $40$에서 일치.
$\ln\min\lvert E\rvert$의 기울기: $-0.693$ (이론 $\ln r=-0.693$), $-0.224$ (이론 $-0.223$).

### 샘플링: 무질서

비자명 사슬 $(0.5,1)$, 셀 20개, 실현 $M=40$, $x=\log_{10}\min\lvert E\rvert$ 평균 ± 표준오차.

| 세기 $s$ | hopping (대칭 유지) | 온사이트 (대칭 깨짐) |
|---|---|---|
| 0.1 | $-6.19\pm0.02$ | $-1.74\pm0.06$ |
| 0.2 | $-6.11\pm0.05$ | $-1.42\pm0.07$ |
| 0.3 | $-6.25\pm0.08$ | $-1.40\pm0.08$ |
| 0.4 | $-6.11\pm0.10$ | $-1.23\pm0.09$ |

표준오차는 $M$이 늘면 대략 $1/\sqrt M$로 준다 ($M=5\to160$: hopping $0.111\to0.034$, 온사이트 $0.213\to0.040$). 작은 $M$에서는 SE 자체가 흔들린다.

### 해석

- 카이랄 대칭: 세기 0.3, 실현 40개에서 $\lVert\Sigma H\Sigma+H\rVert$ 평균은 hopping 0, 온사이트 2.17. 고유값 쌍의 어긋남은 각각 $2.2\times10^{-15}$, 0.16.
- 회전수: $(1,0.5),(0.5,1),(2,1),(1,3)$에서 $0,1,0,1$. Zak phase 크기 $\lvert\gamma\rvert/\pi$도 같고 $t_2$ 스캔에서 0, $\pi$로 양자화 (벗어남 $<10^{-15}$). $\gamma=\pi W$는 이론에서 **인용**하고 계산만 했다.

### 한계

| 확인하지 않은 것 | 확인 방법 |
|---|---|
| 큰 무질서($s>0.4$)에서 벌크 갭이 닫힐 때 | 세기를 키우며 벌크 갭과 $\min\lvert E\rvert$를 함께 추적 |
| 사슬 길이 20셀, 균등분포만 | 더 긴 사슬, 다른 분포로 반복 |
| 실제 물질(폴리아세틸렌)의 $t_1,t_2$ | 문헌의 hopping 값으로 같은 계산 반복 |
| 보호의 엄밀한 정리(지수 정리), 벌크–경계 대응의 일반 증명 | 이론에서 인용 (이 프로젝트는 수치 확인까지) |
| 2차원(그래핀), 전자 사이의 상호작용 | 이 모델의 범위 밖 |

1차 섭동 식은 벌크 상태와의 섞임(더 높은 차수)을 무시한 어림이다. 규약: 유한 사슬이 A 원자에서 시작하고 첫 결합이 $t_1$이다. 이 규약을 바꾸면 갭 안 상태가 생기는 사슬이 뒤바뀐다.
