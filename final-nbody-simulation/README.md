# 기말고사 프로젝트 — N체 중력 시뮬레이션

뉴턴 중력 하 N개 입자의 운동을 수치적분으로 시뮬레이션하는 프로젝트입니다.

## 환경
- Python 3.13.9
- 필요 패키지: numpy, matplotlib, scipy
- 실행 환경: VS Code + Jupyter 확장 (base 커널)

## 실행 방법
1. `nbody-simulation.ipynb`를 VS Code 또는 Jupyter에서 엽니다.
2. 상단 메뉴에서 Restart → Run All로 처음부터 순서대로 실행합니다.
3. 입자 궤적 애니메이션/그래프가 순서대로 출력됩니다.
